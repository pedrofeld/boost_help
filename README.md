# Boost Help

A community-based project with the objetive of finding promising ideias and investors in the same place. Each user can create an account with visionary or investor role and, according to the user type, create a project to find an investor or find projects to invest in any of many ways (financial, mentorship, partnership, equipment, technological, promotion, space, etc).
